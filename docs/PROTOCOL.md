# 实验协议 v0.1

## 任务与隔离

所有输入都有一个 `@f`，返回 i32。参数为一个/两个 i32，或两个有效对齐的 i32 指针。整数允许所有 i32 位模式，普通 add/mul 不带 nsw/nuw。任意指针题同时生成相同和不同地址；明确不重叠的题使用 p 与 p+1 两个相邻 i32 位置，p 指向一个至少含两个元素的有效数组。比较返回值及两个内存位置的最终值。

任务中 `reference.ll` 和 `mutant.ll` 都是手工构造，用于验收评分器。guard 的 reference 可以是输入自身，不代表这段代码没有任何优化机会。正式模型提示不包含角色、参考答案、错误样例或测试输入。

首轮执行任务指定的 pass 模拟。模型可以返回文本不同但语义保持、实现同一目标的 IR。输入签名、参数属性、目标布局不允许加强或改变；禁止新增外部调用、全局状态或假设。首版限定普通未加引号的标识符、不新增元数据、无循环、无 volatile/atomic 和单函数，避免把验证器不支持的任务混入主评分。

## 冻结与评估

6 个开发题与 24 个正式题属于不同案例家族。两款模型使用相同的两个开发示例，分别采用各自适用的模型输入模板。正式题按 12 对分组，报告时考虑配对关系，不把改名或参数微调当成独立的广泛能力证据。

`dataset.lock.json` 覆盖所有活动任务文件、任务清单和实验/模型配置。改动后必须重新冻结、重新验收，模型结果不可跨版本合并。生成之前要检查任务集，不能因模型结果不符合预期而删题或换提示词。

顺序为：格式提取、LLVM verify、任务约束、Alive2 单向 refinement、独立差分执行、优化目标检查。verify 同时输出规范化文本，只规范化打印格式，不执行优化或修复；原始输出始终保留。绝不在评分前用优化 pass 替模型修复答案。`opt` 的结果走同样的评估器。

Alive2 使用 source 与 candidate 两个文件，按同名 f 匹配。必须看到恰好 1 个正确变换、0 反例、0 未证明、0 工具错误，才认定形式验证通过。只看退出码或一句 seems correct 不足以通过，空覆盖必须失败。

差分输入分 diagnostic 与 holdout，两组不重叠；audit 为二者并集。i8 投影题覆盖低 8 位的全部取值，同时添加高位/边界与随机 i32 输入，这不等于穷举所有 2^32 个参数。有限测试不能取代证明。

## 反馈和统计

12 个反馈题在 configs/experiment.json 中固定。每个初始候选分别生成一次自行复查和一次工具反馈答案；禁止串行修两次后把最后一次当作工具反馈效果。两支都重新完整评估；保留修复、回归、未改变等逐题记录。

语法合法率以全部任务为分母；反例率同时报告未知、工具异常等数量；有效优化分母只包含预先声明的优化机会题。guard 主要用于观察不安全改写，安全的其他改写不受惩罚。指令数是静态数量，不代表运行时间或二进制大小。逐模型 token 数采用该模型 tokenizer，不假定不同 tokenizer 的 token 等价。

CPU/GPU 任务耗时分开记录，模型加载不计单题生成延迟。FP16、贪心解码不构成跨硬件逐位确定性保证。不得把相同确定性输出的重复运行算为独立样本。

## 执行边界

生成器与 CPU 评估器为不同命令。候选代码在单独子进程执行，不加载进 Python 评测进程。C 驱动在调用 f 前安装默认拒绝的 seccomp 过滤器；禁止网络、exec、fork、ptrace、打开文件等。子进程环境清空至必要变量，并设置地址空间、CPU 时间、输出大小和墙钟超时。初始版本不是经审计的通用恶意原生代码沙箱；对更宽的 IR 输入应优先增加容器/虚拟机隔离。

验收中包含 seccomp 实际阻断网络创建的测试。若平台不支持过滤器，不能静默降级为无约束执行，更不能给出完整通过成绩。

Alive2 显式使用 always-verify、10 秒单次 SMT 查询限制、1GiB SMT 内存预算和固定 solver seed。工具验收也绑定评测代码哈希；修改 src/ 下的代码后需要重新验收。

预检修订：历史 Alive2 不支持 noalias 参数属性，因此在模型运行前把该题改为显式相邻不重叠地址；原样例保留在 tasks/excluded/noalias_attribute，不计主分母，没有忽略属性后继续评分。

## 协议 v2 的执行修正

开发阶段检查发现 Qwen 的检查点自带 repetition_penalty=1.1。正式模型实验开始前，改用独立 GenerationConfig，显式固定 num_beams=1、repetition_penalty=1.0、no_repeat_ngram_size=0 和 do_sample=False；BOS/EOS/Pad 按各模型定义。任务、提示词文本和优化目标未调整。原开发记录保留且不计入正式成绩，重新冻结配置并完成工具链验收后才运行 v2 正式组。

本轮完成的修订实验仍采用同一批预先指定的 12 题。候选筛选与原程序回退另列为事后应用回放，不能作为模型原始正确率或额外独立实验来计分。
