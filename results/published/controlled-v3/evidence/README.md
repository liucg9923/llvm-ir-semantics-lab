# Complete evidence

The archive preserves all raw runs and per-case evaluations, every native input/output, LLVM/Alive2 logs, development revisions A and B, immutable snapshots, gates, infrastructure status, figures and source code. No model weights or credentials are included.

The embedded FILES.sha256.json identifies each archived file. Verification reads the archive without extraction. The archive includes repeated validation copies with explicit lineage; they are not counted as independent model calls.
