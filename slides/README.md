# 课堂展示材料（草稿）

`classroom-draft.pptx` 为目前的 10 页工作草稿：

1. 程序变换中的语义保持：编译器与大模型的能力差距。
2. 四个需要回答的问题。
3. 展示流程：认识编译器、构造任务、验证分析、总结使用方法。
4. 后七页仍为原有编译器后端生成资料，尚未改成完整的新实验叙事。

本文件没有两款模型的实测成绩。不要把后端函数生成指标与本项目 IR 语义验证指标混用。

PPT 中的第三方论文图表和资料出处见页面/备注，其权利归相应作者，不因本仓库的 Apache-2.0 许可而被重新授权。发表或复用时应保留来源并遵守适用条款。

公开副本已清除作者标识和 WPS 自定义追踪元数据；可见内容、备注、图片与版式保持原样。

15 分钟讲述可按“主题与问题、一个具体语义例子、三组选手与验证标准、真实结果与反例、反馈实验、编程实践”展开。模型结果部分须待实测后补充，当前不填预期分数。
